# SentinelOps — Autonomous AI Operations Agent

SentinelOps is an autonomous AI Operations agent built to handle infrastructure triage, root-cause diagnosis, and policy-governed remediation.

## Features
- **13-Step Triage Workflow**: Ingests telemetry, extracts logs, diagnoses root causes, and verifies recovery.
- **Risk-Tiered Governance**: Automatically executes low-risk **GREEN** actions while gating **YELLOW** actions for approval.
- **Immutable Audit Logging**: Generates full audit packages for compliance.
